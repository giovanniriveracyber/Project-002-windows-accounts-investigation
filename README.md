\# Windows Accounts Investigation (Project-0002 )

\> A guided Windows account investigation completed as part of the \*\*Giovanni Rivera Cyber Academy\*\*.

\---

\#\# About This Investigation

This repository documents my second cybersecurity case file as I build practical Security Operations Center (SOC) investigation skills.

Rather than focusing on memorizing commands, this investigation focused on answering real investigative questions, collecting evidence, documenting findings, and explaining the reasoning behind each conclusion.

This project represents hands-on practice completed as part of my long-term journey toward an entry-level cybersecurity career.

\---

\#\# Investigation Scenario

A Windows workstation was reviewed to establish a baseline understanding of local user accounts.

The investigation focused on identifying:

\- Local user accounts  
\- Detailed account information  
\- The account running the current Command Prompt session  
\- Why multiple sources of evidence should be used during an investigation

\---

\#\# Investigation Objectives

\- Enumerate local Windows user accounts  
\- Investigate a specific user account  
\- Verify the current user session  
\- Practice evidence collection  
\- Document findings professionally  
\- Strengthen investigative reasoning

\#\# Key Lessons Learned

The biggest lesson from this investigation was that cybersecurity investigations begin with questions—not commands.

Each command answers a different investigative question.

Combining multiple evidence sources provides a more complete understanding than relying on a single command.
